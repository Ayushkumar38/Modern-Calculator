# 🧮 Modern Calculator

A clean, modern, and responsive calculator built using **HTML, CSS, and JavaScript**. This project provides a simple and interactive interface for performing basic mathematical calculations directly in the browser.

## 🚀 Live Project

🔗 **GitHub Repository:**
https://github.com/Ayushkumar38/Modern-Calculator

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔢 Decimal number support
* 🧹 Clear/reset functionality
* ⌫ Delete/backspace functionality
* 📱 Responsive design
* 🎨 Modern and user-friendly interface
* ⚡ Fast calculations using JavaScript

## 🛠️ Technologies Used

| Technology     | Purpose                                   |
| -------------- | ----------------------------------------- |
| **HTML5**      | Structure of the calculator               |
| **CSS3**       | Styling, layout, and responsive design    |
| **JavaScript** | Calculator functionality and interactions |

## 💻 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Ayushkumar38/Modern-Calculator.git
```

### 2. Open the project

Go to the project folder:

```bash
cd Modern-Calculator
```

### 3. Run the calculator

Open `index.html` in your web browser.

That's it! 🎉

## 🎯 Project Purpose

The purpose of this project is to practice and demonstrate fundamental **front-end web development** concepts, including:

* HTML page structure
* CSS styling and responsive layouts
* JavaScript DOM manipulation
* Event handling
* Basic mathematical operations
* Building an interactive web application
